## Spec

Keep the Vite frontends type-safe against the FastAPI OpenAPI schema, with a generated client that is never hand-edited.

- **depends on**:
  - ARCH-01
- **files**:
  - tools/codegen/export_openapi.py
  - packages/api-client/openapi.json (generated, committed)
  - packages/api-client/orval.config.ts
  - packages/api-client/package.json (scripts `generate`, `typecheck`)
  - packages/api-client/src/generated/ (generated, committed)
  - tools/ci/check_client_drift.sh
  - apps/web/src/routes/index.tsx (uses the generated health hook)
  - apps/api/tests/test_openapi_export.py
  - e2e/web/health.spec.ts (Playwright)
- **steps**:
  - 1. `tools/codegen/export_openapi.py` imports `aip.main.create_app()`, calls `app.openapi()` and writes `packages/api-client/openapi.json` with `sort_keys=True`, 2-space indent and a trailing newline, so output is byte-stable. FastAPI `operation_id`s are generated as `<tag>_<function name>` so hook names are stable.
  - 2. Generate types with `openapi-typescript` (`src/generated/schema.ts`) and the TanStack Query client with orval (`src/generated/endpoints/`), both from `openapi.json`. `pnpm --filter api-client generate` runs both.
  - 3. Every generated file starts with `// @generated by packages/api-client — do not edit`. A CI step fails if any file under `src/generated/` lacks the header.
  - 4. `tools/ci/check_client_drift.sh`: `uv run python tools/codegen/export_openapi.py && pnpm --filter api-client generate && git diff --exit-code -- packages/api-client`. Non-zero exit prints the diff.
  - 5. `apps/web` depends on `api-client` (`workspace:*`); its index route renders the data from the generated health hook (operation id `platform_health` → `usePlatformHealth()`). `pnpm --filter web build` runs `tsc --noEmit` first.
- **acceptance**:
  - Changing a Pydantic response model without regenerating fails CI.
  - Generated code is never hand-edited (header check).
  - `apps/web` builds against the current schema.
- **tests**:
  - **unit**:
    - `export_openapi.py` produces valid JSON containing the path `/api/v1/health`, and two runs give byte-identical files.
  - **integration**:
    - Run the drift check on a clean tree. Expected: exit 0.
    - Add a field `uptime_s: int` to the health response model and run the drift check. Expected: exit 1 and the diff names `uptime_s`.
    - Remove the header from one generated file. Expected: the header check exits 1 naming that file.
    - Run `pnpm --filter web build`. Expected: 0 type errors.
  - **e2e**:
    - Playwright (`e2e/web`): with the API running and `apps/web` served by `vite preview` (proxying `/api` to the API), open `/`. Expected: the page shows the status `ok` from the generated hook and the console has no errors.
