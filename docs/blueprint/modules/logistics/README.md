# Site logistics & mobilisation (`logistics`)

- **Group:** Field operations
- **Phase:** P3

Getting the site ready to start and controlling what arrives on site.

A mobilisation readiness checklist per project (permits, inductions, site establishment, utilities, access) with a target start date, plus delivery control: gates with operating hours and slot capacity, laydown zones and a delivery booking board linked to purchase orders.

Features:
- Mobilisation plan with readiness items grouped by area and a target commencement date
- Readiness status roll-up showing what still blocks a start
- Gates, opening hours and delivery slot capacity
- Delivery booking board linked to POs and expected docket
- Laydown zones on a site plan

Interacts with:
- Supplier catalogue, requisitions & POs: deliveries link to POs
- Stock, consumables & materials: received goods enter stock
- Certificates, competency & calibration gate: inductions and permits required to mobilise
- Projects, sites & classification: project start date
