- **walkthrough**:
  - User opens the project dashboard and sees the KPI strip and tiles filtered by their permissions.
  - User enters edit mode and adds a tile bound to a saved view.
  - Tiles the user cannot access show as restricted.
  - User drills into a tile to open the filtered register.
  - User opens the heatmap to find areas with poor status and drills into the subtree.
  - User views trends from nightly snapshots and compares periods.
  - User opens CUI/NDT analytics and filters by system, severity and area.
  - User picks a report template, sets parameters and previews.
  - User generates the report; an immutable output with content hash is stored in documents.
  - Reviewer signs off the report through the workflow engine.
  - User schedules a digest with recipients; each run is logged.
