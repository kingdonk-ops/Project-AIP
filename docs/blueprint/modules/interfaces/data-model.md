# Interface management — Data model & schema


- **notes**: Matrix and heat-map are queries over interfaces grouped by package pair, not stored tables. Required dates are also written to the shared deadlines table in the tasks module, and escalation items create tasks. Default escalation timings are left as ladder data until the owner sets them. Whether external parties get logins is open, so interface_party_access works for either internal or portal users. The number is generated by shared numbering.
