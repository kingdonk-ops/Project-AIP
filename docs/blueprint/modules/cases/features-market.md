# User-authored playbooks — Feature scout


- **abilities seen in market**:
  - Step-by-step in-app guides with highlighted screen elements
  - Role-based onboarding tours
  - Checklists with completion tracking
  - Controlled procedures with versioning and acknowledgement
  - Embedded screenshots and deep links
  - Analytics on guide usage and drop-off
  - Templates for common workflows
  - Assignment of training to users with due dates
- **suggestions**:
  -
    - **effort**: M
    - **feature**: Fold into controlled procedures with read-and-acknowledge tracking
    - **why**: Matches ISO 9001 needs and reuses document control rather than building a separate authoring tool.
  -
    - **effort**: S
    - **feature**: Markdown guides with terminology tokens
    - **why**: A cheap first version that automatically adopts each market's renamed terms.
  -
    - **effort**: S
    - **feature**: Guides launched from a screen with a help button
    - **why**: Contextual help for field users on tasks like raising a CUI inspection raises adoption with minimal build.
  -
    - **effort**: M
    - **feature**: Link acknowledgements to competency records
    - **why**: Evidence that a person read a procedure can feed the eligibility gate for relevant tasks.
