# Resources & crews (basic) — Feature scout


- **abilities seen in market**:
  - Person and crew register with role, skills and availability
  - Assignment calendar by day with double-booking warnings
  - Skills and ticket matching when assigning to work
  - Leave and roster patterns such as FIFO or fly-in fly-out
  - Utilisation view across projects
  - Labour and plant pre-fill into daily records
  - Optional cost rates by resource type
  - Request and approval of resources between projects
- **suggestions**:
  -
    - **effort**: S
    - **feature**: Qualification-aware assignment warning and optional hard-block
    - **why**: Use the unused competencies column and the eligibility gate so an expired NDT level or missing ticket is flagged before assignment.
  -
    - **effort**: M
    - **feature**: Roster pattern field for FIFO and swing schedules
    - **why**: Western Australian resource projects run on rosters, and availability that ignores them produces false conflicts.
  -
    - **effort**: S
    - **feature**: Crew templates reused across scopes
    - **why**: Standard crews such as inspector plus rope access technician can be assigned in one action, which keeps this module basic but useful.
  -
    - **effort**: S
    - **feature**: Assignment feed into inspection inspector field
    - **why**: Avoids double entry and ensures the assigned person is the one the eligibility gate checks.
