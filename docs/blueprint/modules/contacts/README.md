# Contacts & companies (`contacts`)

- **Group:** Commercial
- **Phase:** P1

A shared directory of clients, subcontractors, suppliers and consultants.

Companies and people with roles, contact details and links to projects. Used by procurement, transmittals, correspondence and the portal.

Features:
- Companies and people
- Roles per project
- Import from CSV
- Duplicate detection

Interacts with:
- Supplier catalogue, requisitions & POs: suppliers
- Transmittals & correspondence: recipients
- Client & subcontractor portal: external users

AIP repo status and plans:
- Not built
